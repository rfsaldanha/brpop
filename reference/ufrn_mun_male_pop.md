# Municipality yearly male population estimates per age group, from 2010 to 2030

A dataset containing male population estimates for Brazilian
municipalities by age group from 2010 to 2030.

## Usage

``` r
ufrn_mun_male_pop()
```

## Details

The estimates were computed by the LEPP laboratory from the Demography
Department/UFRN.

- code_muni:

  municipality 7 digits code

- year:

  year of the estimate

- age_group:

  age group

- pop:

  population estimate
