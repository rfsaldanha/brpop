# Municipality and health region code table

A dataset containing municipality and health regions codes.

## Usage

``` r
mun_reg_saude
```

## Format

A tibble with 5,592 rows and 2 variables:

- code_muni:

  municipality 6 digits code

- codi_reg_saude:

  health region 4 digits code

## Source

The 2025 assignment of Boa Esperança do Norte to the Teles Pires health
region is documented by the Mato Grosso State Health Department, CIB/MT
Resolution No. 143 of 22 May 2025.
