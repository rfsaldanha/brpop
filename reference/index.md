# Package index

## Population datasets

Population estimates datasets available at the package.

- [`datasus_mun_female_pop()`](https://rfsaldanha.github.io/brpop/reference/datasus_mun_female_pop.md)
  : Municipality yearly female population estimates per age group from
  2000 to 2021
- [`datasus_mun_male_pop()`](https://rfsaldanha.github.io/brpop/reference/datasus_mun_male_pop.md)
  : Municipality yearly male population estimates per age group from
  2000 to 2021
- [`datasus2024_mun_female_pop()`](https://rfsaldanha.github.io/brpop/reference/datasus2024_mun_female_pop.md)
  : Municipality yearly female population estimates per age group from
  2000 to 2024
- [`datasus2024_mun_male_pop()`](https://rfsaldanha.github.io/brpop/reference/datasus2024_mun_male_pop.md)
  : Municipality yearly male population estimates per age group from
  2000 to 2024
- [`ufrn_mun_female_pop()`](https://rfsaldanha.github.io/brpop/reference/ufrn_mun_female_pop.md)
  : Municipality yearly female population estimates per age group, from
  2010 to 2030
- [`ufrn_mun_male_pop()`](https://rfsaldanha.github.io/brpop/reference/ufrn_mun_male_pop.md)
  : Municipality yearly male population estimates per age group, from
  2010 to 2030
- [`ibge_pop()`](https://rfsaldanha.github.io/brpop/reference/ibge_pop.md)
  : Municipality population from IBGE, 2000 to 2025

## Totals

Functions to return the total population per year and geographical unit.

- [`mun_pop_totals()`](https://rfsaldanha.github.io/brpop/reference/mun_pop_totals.md)
  : Municipality yearly population totals
- [`regsaude_pop_totals()`](https://rfsaldanha.github.io/brpop/reference/regsaude_pop_totals.md)
  : Health region yearly total population estimates
- [`uf_pop_totals()`](https://rfsaldanha.github.io/brpop/reference/uf_pop_totals.md)
  : UF yearly population totals
