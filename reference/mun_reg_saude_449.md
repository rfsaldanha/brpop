# Municipality and health region (449) code table

A dataset containing municipality and health regions codes, following
the 449 units specification.

## Usage

``` r
mun_reg_saude_449
```

## Format

A tibble with 5,571 rows and 2 variables:

- code_muni:

  municipality 6 digits code

- codi_reg_saude:

  health region 5 digits code

## Source

The 2025 assignment of Boa Esperança do Norte to the Teles Pires health
region is documented by the Mato Grosso State Health Department, CIB/MT
Resolution No. 143 of 22 May 2025.
