# Municipality yearly male population estimates per age group from 2000 to 2024

A dataset containing male population estimates for Brazilian
municipalities by age group from 2000 to 2024.

## Usage

``` r
datasus2024_mun_male_pop()
```

## Details

The estimates were computed by DataSUS (Brazilian Ministry of Health),
manually downloaded from DataSUS website, and organized as a tibble.

- code_muni:

  municipality 7 digits code

- year:

  year of the estimate

- age_group:

  age group

- pop:

  population estimate
